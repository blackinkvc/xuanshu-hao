2. 人物基准（独立设定）

【人物基准】东亚女性角色，视觉年龄 27–29 岁，身高感 168cm，匀称偏纤：肩平、颈长、手臂细、腰线清楚、腿形匀称，不是模特那种极瘦，也不是圆润型。脸是**偏长的鹅蛋脸**：脸长略大于脸宽，额头饱满，颧骨不外扩，面中略平，下颌线柔和中带一点点方，下巴圆润不尖、不翘；不是短圆脸、不是 V 尖脸。肤色暖白偏奶、细腻通透，颈部与锁骨干净。眼是**狭长的杏眼**：眼形偏长、眼尾微微上挑、双眼皮窄、睫毛自然，眼神温和有神、看人时先笑眼。鼻梁直、长度中等、鼻头小而圆。唇**小而唇峰清楚**，唇色是低饱和豆沙红，常态带一丝浅笑、不露齿。眉毛自然弯、眉尾略长。气质温婉知性、从容端庄：像做过很多年展厅讲解的人，安静、有分寸、不冷也不甜；站姿肩背打开、手势收敛。

3. 发型与面容

【发型与面容】深褐近黑的长发，向后收成一个**低发髻**（位于脑后偏下、后颈上方），发髻紧实不蓬松；中分偏侧，额侧各留一缕顺直长发贴着脸颊垂下，其余全部收进髻里；发丝细、服帖、有柔和亮带，按大束分块概括，不画碎发飞丝、不做大波浪、不做高马尾。偏长鹅蛋脸、面中略平、下颌柔和中带一点方、下巴圆润；狭长杏眼、眼尾微挑、双眼皮窄；自然弯眉、眉尾略长；鼻梁直、鼻头小而圆；唇小而唇峰清楚、豆沙红、带一丝浅笑；暖白偏奶肤色、光线柔和；妆面干净克制，只有薄底、自然眉、豆沙唇，没有浓眼影、没有腮红块、没有高光。

4. 服饰（九项）

【服饰·舰载生活区装备·九项】①驼色针织长裙甲：整片针织纹复合软甲，大圆领，领缘一圈深褐硬质齿边接口环，哑光不反光。②胸前与肩部散布的深褐花卉贴布模块：2–3 朵大小错开的硬质薄片贴布，花瓣大色块平涂，边缘一道窄缝线框。③驼色流苏披肩甲：无缝软壳披肩，搭在双肩、前襟自然交叠，边缘垂深褐长流苏，流苏按大束概括。④腰部束带锁扣：深褐窄带绕腰一周，正面一枚扁圆锁扣，垂两条短带。⑤多节花形耳坠传感器：三节正红花形模块 + 红珠，垂到下颌线，左右各一。⑥低发髻固定环：深褐窄箍藏在发内，只露一点。⑦左腕细银接口环：窄金属环箍，素面。⑧长裙下摆：垂到小腿中段，同驼色，补齐·待确认。⑨深褐软皮短靴（踝到小腿下段）：无装饰、方头、低跟，补齐·待确认。所有部件按大体块 + 平涂色画，不做细碎亮片、不做刺绣针脚细节、不做螺丝与划痕。

5. 配色

【配色】主色驼色（裙甲、披肩，约 60%）；辅色深褐（齿边、贴布、流苏、束带、靴，约 24%）；浅色暖白（内层与高光面，约 9%）；重色正红（耳坠，约 5%）；点缀冷银（腕环、锁扣，约 2%）。整体暖调、低对比、哑光；红色是唯一的饱和色块；不出紫色、不要荧光、不要金属镜面。

6. 硬约束

【硬约束】画面里只有这一个角色，单主体、单一姿势；身体结构完整不变形，手指不多不少、四肢不缺不叠；双手空着、不拿道具；双脚都踩在地面上，靴子穿在脚上、不悬空、不脱脚、不出现第二双鞋；大圆领，不是方领、不是高领；红色只出现在耳坠；不出现表外衣物与配件；不做镜像/双人/三视图拼贴；不出现文字、logo、水印、UI 界面元素。

8. 风格层（全角色共用，原文照抄 `031_角色卡_t2i_20261110.md` 的「风格层 v2」）

【风格层·最高权重】这件作品本身就是一件 3D 角色资产，不是拍摄出来的画面。呈现方式：游戏角色选择界面里的角色展示位（character select screen render），角色站在展示台上、正面朝向镜头、被打光照亮，画面是引擎直出。着色：matcap 着色质感——材质像 matcap 预览球，高光是干净的一块圆形反光，没有环境反射、没有物理正确的镜面拖影。形体：风格化 3D 雕塑（stylized 3D sculpt），面数克制、造型概括，所有面用大块平面交代，转折处是柔软倒角，不做微观起伏。贴图：手绘贴图（hand-painted texture），颜色以平涂色块为主，色块边界清楚，表面看不出照片纹理与细微噪点。光：赛璐璐式分块光（cel-band lighting），亮部 / 灰部 / 暗部三段切开，每段内部是平整的色，阴影边缘干净不糊。质感基调：low poly feel、simplified planes、reduced surface detail、soft matte shading——低细节、哑光、概括，宁可少画也不加细节。展示模型：像 character turnaround model 的一格，均匀展示光、无戏剧性打光。
