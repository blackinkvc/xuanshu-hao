2. 人物基准（独立设定）

【人物基准】东亚女性角色，视觉年龄 18–19 岁，身高感 165cm，纤瘦：肩窄、颈细、手臂细、腰细、胯窄，腿细而直，整体是少女的清瘦身形，不是成熟曲线型。脸是**小巧的瓜子脸**：额头圆润、颧部柔和不外扩、下颌线一路收窄、下巴小而圆尖；脸的面积小、五官占比大。肤色瓷白偏冷粉、近乎无瑕，颈与肩的线条干净。眼是**大而圆的杏眼**：眼裂圆、眼尾平缓略下垂、双眼皮浅而宽、黑眼珠占比大、卧蚕明显；眼神是安静的、略带怯的直视。鼻梁细而短、鼻头非常小、鼻翼窄。唇小，唇峰柔和、上下唇厚度接近，唇色浅粉，常态微微张开一线。眉毛淡而柔、眉形平缓。气质温婉、安静、带一点怯：肩常微微内收，手势轻。

3. 发型与面容

【发型与面容】栗棕（暖褐）长发，中分偏侧，发质直而厚、柔顺有光泽，全部拨到左肩前，发尾垂到胸下；右侧头发别在耳后，右耳上方别一朵**六瓣大粉花**发饰。不是大波浪、不是卷发、不是黑色、不是短发、不是盘发、不是双马尾。小巧瓜子脸、下颌收窄、下巴小而圆尖；大而圆的杏眼、眼尾平缓略垂、双眼皮浅宽、卧蚕明显；淡而柔的平缓眉；鼻梁细短、鼻头极小；唇小、浅粉、微微张开一线；瓷白偏冷粉肤色；妆面极淡，只有薄底、极细内眼线、浅粉唇，没有眼影色块、没有腮红、没有高光颗粒。

4. 服饰（九项）

【服饰·舰载生活区装备·九项】①抹胸印花长裙甲：整片奶白底硬质软甲，表面珊瑚粉大花按大色块平涂印花，无肩带、抹胸式，哑光。②抹胸防滑接口箍：上缘内侧一圈窄硬质箍，外侧只露一道细线。③高开衩侧片：左侧开衩到大腿中段，衩缘一道窄包边。④长裙下摆：垂到脚踝上方，同印花，摆缘窄包边。⑤锁骨接口链：细银链 + 一枚小水滴形模块。⑥左腕细银接口环：窄银环 + 一枚小米粒大小蓝点模块。⑦侧头发饰模块：六瓣大粉花别在右耳上方，花瓣硬质平涂。⑧赤足：不设鞋袜，脚趾与脚背完整入画。⑨裙后中缝接口：一道窄硬质缝线，补齐·待确认。所有部件按大体块 + 平涂色画，不做亮片、不做真实布料褶皱细节、不做刺绣针脚。

5. 配色

【配色】主色奶白（裙甲底，约 45%）；大块珊瑚粉（印花大花、发花，约 30%）；栗棕（发，约 14%）；冷银（项链、腕环，约 6%）；浅粉（唇，约 3%）；一点冷蓝（腕环小点，约 2%）。整体浅暖调、低对比、哑光；不出现黑色大块、不出紫色、不要荧光、不要金属镜面。

6. 硬约束

【硬约束】画面里只有这一个角色，单主体、单一姿势；身体结构完整不变形，手指不多不少、四肢不缺不叠；双手空着、不拿花、不拿道具；赤足，双脚都踩在地面或台面上、不悬空、不出现任何鞋与袜、不出现第二双鞋；抹胸式，肩颈完全裸露，没有肩带、没有披肩、没有外套；左腿开衩一道，不开两道；不做镜像/双人/三视图拼贴；不出现文字、logo、水印、UI 界面元素。

8. 风格层（全角色共用，原文照抄 `031_角色卡_t2i_20261110.md` 的「风格层 v2」）

【风格层·最高权重】这件作品本身就是一件 3D 角色资产，不是拍摄出来的画面。呈现方式：游戏角色选择界面里的角色展示位（character select screen render），角色站在展示台上、正面朝向镜头、被打光照亮，画面是引擎直出。着色：matcap 着色质感——材质像 matcap 预览球，高光是干净的一块圆形反光，没有环境反射、没有物理正确的镜面拖影。形体：风格化 3D 雕塑（stylized 3D sculpt），面数克制、造型概括，所有面用大块平面交代，转折处是柔软倒角，不做微观起伏。贴图：手绘贴图（hand-painted texture），颜色以平涂色块为主，色块边界清楚，表面看不出照片纹理与细微噪点。光：赛璐璐式分块光（cel-band lighting），亮部 / 灰部 / 暗部三段切开，每段内部是平整的色，阴影边缘干净不糊。质感基调：low poly feel、simplified planes、reduced surface detail、soft matte shading——低细节、哑光、概括，宁可少画也不加细节。展示模型：像 character turnaround model 的一格，均匀展示光、无戏剧性打光。
