机体编号
EQ-480 · Z-1「镇」
分类
警备与秩序 · 镇压机兵（双足）
形制
无头双足反关节步行机。肩部收成一段平的装甲传感槽，槽内嵌一条窄传感器缝；躯干是一块向前探出的宽平装甲块；双足反关节，足端是整块平底装甲脚。无颈、无面部、无单眼、无头顶结构。
尺度
机身限高 2.4 m、最窄通过宽度 0.78 m，可单机通过标准气密门而不拆门框（沿用 EQ-480 原档形制依据）。
材质与工艺
哑光黑装甲板，表面近乎不反光；块与块之间是清楚的接缝与沉台，不靠描边勾线；承力框外露，装甲片可单片更换。
关节与执行
髋、膝、踝三处钢制转盘轴承裸露在外，配短程执行推杆；不做外露长液压杆。
功能凸起
背部鳍片散热块、肩部两根鞭状天线、胸前一条窄传感器缝；无装饰性花纹、无大面积橙色点缀。
表面标记
白色模板喷字 Z-1，喷在大腿外侧装甲板上。
编制归属
舰务与安保部 · 各甲板警备位；12 台（A 2 / B 2 / C 3 / I1 2 / T3 2 / 机库 1）。
舱位
各甲板固定警备位，不外借。
武装
非致命档为主用（声光威慑 + 导电液喷射 + 压控），致命档为双人授权下的近距定向能脉冲；本轮造型未画武器模块。
维护
装甲片单片更换；关节轴承与推杆每 500 h 检查；续航 6 h，换电 90 s。
外观锚点
哑光黑；平肩无头；反关节双足；三处钢制轴承外露；白字 Z-1；鳍片散热块与鞭状天线
