2. 人物基准（独立设定，与 032 / 033 明确分开）

【人物基准】东亚女性角色，视觉年龄 22–23 岁，身高感 160cm，骨架娇小、肩窄而圆、腰细、腿相对短，整体比例偏可爱而非修长；站姿放松，重心常落在一条腿上。脸小而偏圆的心形脸，下巴略尖但两颊带一点婴儿肥，苹果肌饱满。肤质暖白偏奶油，皮肤细腻、脸上有血色，不是冷白、不是瓷白。眼型大而圆，双眼皮宽，眼尾略下垂，卧蚕明显，看人时是直接的正视、不带审视。鼻梁中等高度、鼻头小巧圆润。唇偏厚、唇峰不明显、常态微微张开，唇色浅珊瑚。气质是生活流甜美：安静、不张扬、不设防，像城市里被照顾得很好的女孩；不是冷艳、不是厌世、不是御姐。

3. 发型与面容

【发型与面容】纯黑长发，中分、发量极大、直发垂到腰，发尾齐整不做碎层次；按大束分块概括，每束有明确的亮带与暗带，不画一根根碎丝。脸小而偏圆的心形脸，两颊有柔和婴儿肥，下颌线收成一个小而钝的尖；眼型大而圆、双眼皮宽、眼尾略下垂、卧蚕明显；眉毛是自然的平弯眉、眉色偏淡、眉尾略下垂；鼻梁中等高度、鼻头小而圆；唇偏厚、唇峰圆钝、唇色浅珊瑚；肤色暖白偏奶油；妆面很淡，只有一层薄底、浅粉腮红、浅珊瑚唇，没有浓眼线、没有高光。

4. 服饰（九项）

【服饰·舰载生活区装备·九项】①白色针织纹软甲背心：整片针织纹复合软甲，哑光、有细密的针织纹但不做真实纱线，V 领，五颗哑光白扣，胸口一枚指甲盖大小的熊形徽记模块，是全身最清楚的软表面件。②缎面内层吊带：哑光缎面单层内层，V 领，领缘一圈细齿边硅胶密封条，下摆藏在裙甲里。③双态百褶裙甲：八片薄硬板叠压成褶，下缘一圈细齿边，内衬藏蓝细格纹复合布，膝上约 12cm，片间留 2mm 深灰缝。④领下嵌入式细链传感器：极细金属链贴领缘走一圈，正面一枚扁平方形传感器。⑤左腕接口环箍：窄金属环箍 + 竖向窄数据窗，窗内冷白指示灯。⑥立领硬质外披：立领铣削件，前襟与袖口走白色明线，短版到腰，可脱外层。⑦平底软壳短靴：软壳复合面，脚踝一圈窄金属锁定环，复合平底无跟。⑧肩线接缝：肩上不加装甲片，只沿肩线走一道极窄浅灰接缝线，与领缘密封条在颈根对接。⑨耳侧接缝扣：耳侧一枚极小金属扣，颧侧一条极细接缝线。所有部件按大体块 + 平涂色画，不做螺丝、铆钉、划痕等细碎装饰。

5. 配色

【配色】主色奶油白（背心、内层吊带，约 52%）；辅色藏蓝（裙甲内衬与外披内里，约 22%）与浅雾灰（接缝线、靴面，约 14%）；点缀色浅香槟（细链传感器、腕部接口片、熊形徽记，约 7%）与冷白指示灯（约 5%）。整体低饱和、暖调偏亮，没有大面积深色、没有金属镜面高光、没有紫色、没有荧光色。

6. 硬约束

【硬约束】画面里只有这一个角色，单主体、单一姿势；身体结构完整不变形，手指不多不少、四肢不缺不叠；肩线上没有任何装甲片、没有护肩、没有金属块；不出现表外衣物与配件；不做镜像/双人/三视图拼贴；不出现文字、logo、水印、UI 界面元素。

8. 风格层（全角色共用，原文照抄 `031_角色卡_t2i_20261110.md` 的「风格层 v2」）

【风格层·最高权重】这件作品本身就是一件 3D 角色资产，不是拍摄出来的画面。呈现方式：游戏角色选择界面里的角色展示位（character select screen render），角色站在展示台上、正面朝向镜头、被打光照亮，画面是引擎直出。着色：matcap 着色质感——材质像 matcap 预览球，高光是干净的一块圆形反光，没有环境反射、没有物理正确的镜面拖影。形体：风格化 3D 雕塑（stylized 3D sculpt），面数克制、造型概括，所有面用大块平面交代，转折处是柔软倒角，不做微观起伏。贴图：手绘贴图（hand-painted texture），颜色以平涂色块为主，色块边界清楚，表面看不出照片纹理与细微噪点。光：赛璐璐式分块光（cel-band lighting），亮部 / 灰部 / 暗部三段切开，每段内部是平整的色，阴影边缘干净不糊。质感基调：low poly feel、simplified planes、reduced surface detail、soft matte shading——低细节、哑光、概括，宁可少画也不加细节。展示模型：像 character turnaround model 的一格，均匀展示光、无戏剧性打光。
