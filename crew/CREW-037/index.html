2. 人物基准（独立设定）

【人物基准】东亚女性角色，视觉年龄 21–23 岁，身高感 172cm，极长腿、上身短：肩窄而平、颈细长、腰细、胯窄，腿长占身高约一半，整体是高瘦的衣架子身形，不是圆润型、不是肌肉型。脸是**小巧偏短的心形脸**：脸宽略大于脸长的视觉感、额头饱满、颧部柔和不外扩、下颌线柔和收窄、下巴小而略尖但不尖锐；不是长脸、不是方脸、不是圆脸。肤色冷白偏粉、通透有光泽，颈与锁骨的骨点清楚。眼是**略长的杏眼**：眼裂长度中等偏长、眼尾微微**下垂**（天然无辜感）、双眼皮明显且窄、黑眼珠占比大、卧蚕浅；眼神安静、不太笑。鼻梁细、鼻头小、鼻翼窄。唇小，上唇薄、下唇略厚，唇色玫瑰豆沙，常态平直不说话。眉毛细、平直略下压。气质**甜酷**：五官是软的，表情是冷的；站姿松但直，重心常落在一条腿上。

3. 发型与面容

【发型与面容】纯黑长发，侧分（约三比七），发量厚，头顶蓬起有高度；从耳下开始起**大波浪**，卷度大而松、不细碎，发尾垂到胸下；脸颊一侧有一缕大卷垂在胸前，另一侧别在耳后。不是中分、不是直发贴头皮、不是栗色/棕色、不是短发、不是盘发。小巧偏短的心形脸、下颌柔和收窄、下巴小而略尖；略长杏眼、眼尾微下垂、双眼皮窄而明显、黑眼珠大；细而平直的眉；鼻梁细、鼻头小；唇小、上薄下略厚、玫瑰豆沙；冷白偏粉肤色；妆面干净，只有薄底、细眼线、玫瑰唇，没有浓眼影、没有明显腮红、没有高光颗粒。

4. 服饰（九项）

【服饰·舰载生活区装备·九项】①黑色细密针织软甲外壳：短款，前襟敞开不扣，门襟与袖口一圈细齿接口边，哑光。②白色硬质蕾丝领环：颈下一圈白色蕾丝纹硬边领环，前中三枚珍珠状接口钉。③双圈珍珠传感器链：两圈哑光珍珠模块，大小错开，垂到胸下。④白色蕾丝高腰短甲裙：整片蕾丝纹硬质壳，高腰，裤脚一圈黑色短流苏护边按束概括。⑤黑色菱格硬壳腰侧挂载仓：小方仓，正面金色 V 形卡扣，短链条斜挂到左髋。⑥黑色尖头硬壳细高跟战靴：尖头、踝部两圈铆钉绑带接口、细金属跟钉，哑光漆面。⑦侧分发内窄箍固定环：藏在发内只露一点。⑧左腕细银接口环：窄金属环箍、素面，补齐·待确认。⑨后颈发际接口片：小片浅银硬片、藏在发下，补齐·待确认。所有部件按大体块 + 平涂色画，不做亮片、不做刺绣针脚、不做螺丝与划痕。

5. 配色

【配色】主色纯黑（软甲外壳、短流苏、挂载仓、战靴，约 52%）；大块白（蕾丝领环、短甲裙，约 30%）；暖白珍珠（传感器链，约 8%）；冷银（接口环、接口片、跟钉，约 6%）；金色只做一枚 V 形卡扣（约 2%）；肤色与唇的玫瑰调（约 2%）。整体黑白高对比、哑光；不出现第三主色，不出紫色、不出荧光、不要镜面反射。

6. 硬约束

【硬约束】画面里只有这一个角色，单主体、单一姿势；身体结构完整不变形，手指不多不少、四肢不缺不叠；双手空着、不拿道具、不拎包；双脚都踩在地面上，高跟鞋穿在脚上、不悬空、不脱脚、不出现第二双鞋；上身穿黑色短开衫、内层白色蕾丝领环，下身穿白色蕾丝短甲裙，三层结构必须都读得出来；珍珠链只一圈位置在胸前，不绕颈两圈以上；不做镜像/双人/三视图拼贴；不出现文字、logo、水印、UI 界面元素。

8. 风格层（全角色共用，原文照抄 `031_角色卡_t2i_20261110.md` 的「风格层 v2」）

【风格层·最高权重】这件作品本身就是一件 3D 角色资产，不是拍摄出来的画面。呈现方式：游戏角色选择界面里的角色展示位（character select screen render），角色站在展示台上、正面朝向镜头、被打光照亮，画面是引擎直出。着色：matcap 着色质感——材质像 matcap 预览球，高光是干净的一块圆形反光，没有环境反射、没有物理正确的镜面拖影。形体：风格化 3D 雕塑（stylized 3D sculpt），面数克制、造型概括，所有面用大块平面交代，转折处是柔软倒角，不做微观起伏。贴图：手绘贴图（hand-painted texture），颜色以平涂色块为主，色块边界清楚，表面看不出照片纹理与细微噪点。光：赛璐璐式分块光（cel-band lighting），亮部 / 灰部 / 暗部三段切开，每段内部是平整的色，阴影边缘干净不糊。质感基调：low poly feel、simplified planes、reduced surface detail、soft matte shading——低细节、哑光、概括，宁可少画也不加细节。展示模型：像 character turnaround model 的一格，均匀展示光、无戏剧性打光。
