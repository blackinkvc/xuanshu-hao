2. 人物基准（独立设定，不套用 031）

【人物基准】东亚女性角色，视觉年龄 25 岁，身高感 170cm，身形瘦高、骨架轻；肩窄而平、锁骨明显、腰线高、腿长；气质冷、静、话少，站姿收着，下巴微收，眼神平直看镜头，不笑或只给一点很淡的礼貌弧度。不是甜系、不是御姐张扬型，是「值更官」那种克制。

3. 发型与面容

【发型与面容】头发是深黑棕色长直发，侧分约 3:7，发量厚，长至胸下，发尾齐整、末端轻微内扣；按大束分块概括，每束有明确的亮带与暗带，不做一根根碎丝，不做夸张蓬松。脸型窄长，颧骨略高，下颌线干净收窄成一个利落的小尖；眼型细长上挑（凤眼），内眼角略尖，双眼皮一道窄线；眉毛细长平直、眉峰很轻；鼻梁高而直，鼻头小而收；唇形薄、唇峰清楚，唇色低饱和豆沙；肤色偏冷白；妆面只保留一道细眼线与唇色，没有腮红、没有高光。

4. 服饰（九项）

【服饰·舰载值更装备·九项】①硬质方领框：领口为方形，四条边平直、四角直角，领框是磨砂复合板铣削件，边缘有一道细倒角高光，内缘一圈硅胶密封条；领深到锁骨下约两指，左右完全对称，是画面里最清楚的硬表面件。②贴体短袖内层：单层复合针织贴身内层，哑光、无布纹；胸口下方一条横向承力带，磨砂带面 + 一个方形金属扣；袖口外侧一圈硬质环箍。③高腰短裙甲：四片叠压硬质裙甲，腰封为复合板环带，片间露出深灰内衬，左前一片外侧嵌一条竖向冷白指示灯条，长度膝上约 15cm。④背部矩形检修窗：腰上至肩胛的镂空窗，四周包复合板边框与密封条，左右各一只旋转锁扣。⑤背部承力链：一条扁平小方环金属链，从颈后两侧斜拉至腰封。⑥过膝软壳长靴：靴筒软壳复合材料，自然堆叠两道褶，脚踝一圈金属锁定环，中空粗跟，黑色复合防滑底。⑦领框下缘嵌入式细链传感器：极细金属链贴着领框下缘走线，正面一枚扁平方形传感器。⑧腕部接口环箍：右腕金属环箍 + 扁平矩形接口片，片侧小指示灯、正面窄数据窗。⑨耳侧接缝扣：耳侧一枚极小金属接缝扣，颧侧一条极细接缝线，颈根一圈软质密封环与领框密封条对接。所有部件按大体块 + 平涂色画，不做螺丝、铆钉、划痕等细碎装饰。

5. 配色

【配色】主色黑（内层、裙甲、长靴，约 65%）；辅色枪灰（领框、卡扣、环箍、踝环、检修窗边框，约 20%）；点缀色香槟金（细链传感器、腕部接口片、锁扣，约 8%）与冷白到浅青指示灯（约 7%，只出现在裙甲灯条与接口片）。整体低饱和、冷调，没有大面积亮色，没有紫色、没有暖橙。

6. 硬约束

【硬约束】画面里只有这一个角色，单主体、单一姿势；身体结构完整不变形，手指不多不少、四肢不缺不叠；肩线上没有任何装甲片、没有护肩、没有金属块；不出现表外衣物与配件；不做镜像/双人/三视图拼贴；不出现文字、logo、水印、UI 界面元素。

8. 风格层（全角色共用，原文照抄 `031_角色卡_t2i_20261110.md` 的「风格层 v2」）

【风格层·最高权重】这件作品本身就是一件 3D 角色资产，不是拍摄出来的画面。呈现方式：游戏角色选择界面里的角色展示位（character select screen render），角色站在展示台上、正面朝向镜头、被打光照亮，画面是引擎直出。着色：matcap 着色质感——材质像 matcap 预览球，高光是干净的一块圆形反光，没有环境反射、没有物理正确的镜面拖影。形体：风格化 3D 雕塑（stylized 3D sculpt），面数克制、造型概括，所有面用大块平面交代，转折处是柔软倒角，不做微观起伏。贴图：手绘贴图（hand-painted texture），颜色以平涂色块为主，色块边界清楚，表面看不出照片纹理与细微噪点。光：赛璐璐式分块光（cel-band lighting），亮部 / 灰部 / 暗部三段切开，每段内部是平整的色，阴影边缘干净不糊。质感基调：low poly feel、simplified planes、reduced surface detail、soft matte shading——低细节、哑光、概括，宁可少画也不加细节。展示模型：像 character turnaround model 的一格，均匀展示光、无戏剧性打光。

镜头 · A 正面半身

【取景·正面半身】832×1216 竖幅，画面上沿在头顶上方约两指，画面下沿裁在胸线下方一掌（能看见领框、胸带与两肩完整），正面平视，角色直视镜头，双手自然垂在身侧不入画。

镜头 · B 动作全身

【姿势·动作全身·一】全身入画，坐在舱室金属长凳上，右腿曲起、左腿自然垂下，右手抬起按在耳侧接缝扣上（像在接通讯），左手撑在身侧；上身前倾一点，视线略偏画面左外侧。
