2. 人物基准（独立设定，不套用 031 / 032）

【人物基准】东亚女性角色，视觉年龄 23 岁，身高感 165cm，身形匀称偏柔；肩线圆润、腰细、胯线柔和、腿型匀称；气质温和、松弛、带一点俏，眼神有笑意但不卖萌；站姿自然放松，重心常落在一侧胯上。不是冷艳型、不是职业克制型。

3. 发型与面容

【发型与面容】头发是深栗棕色大波浪长卷发，中分偏侧（约 4:6），发量蓬松，长度过胸；按大束分块概括，每束是一个完整形体、有明确亮带与暗带，卷度从耳下开始，发尾内扣与外翻混合、走向清楚，不做一根根碎丝。脸型是鹅蛋偏圆，面颊饱满、下颌柔和；眼型圆杏眼，眼尾平，卧蚕明显，双眼皮宽一点；眉毛柔和微弯、眉尾淡；鼻梁中等高度，鼻头圆润；唇形饱满、唇峰柔和，唇色暖玫瑰；肤色暖白；妆面保留很淡的腮红与玫瑰唇，不做皮肤高光、不做亮片。

4. 服饰（九项）

【服饰·舰载医疗监测装备·九项】①硬质方领框：领口为方形，四条边平直、四角直角，磨砂复合板铣削件，边缘一道细倒角高光，内缘一圈密封条；领深到锁骨下约两指，左右对称；上缘两根短承力杆斜拉到肩后。②领框四角金属锁扣：四只方形香槟金锁扣嵌在四角，压住承力杆端头。③领下折叠承力褶：领框下方一道横向折叠的复合面料承力褶，两折、走向清楚、哑光。④无袖肩线：肩缝平贴、顺肩线落下，肩上没有任何覆盖件、没有护肩、没有金属块。⑤高腰短裙甲：四片叠压硬质裙甲，膝上约 18cm，片间露深灰内衬，右前一片嵌竖向冷白指示灯条。⑥硬质腰封环带：复合板环带压住裙甲上缘，正面一个方形金属扣。⑦硬质高跟踝靴：深紫外壳 + 半硬壳模压鞋面，中空金属细跟，脚踝一圈金属锁定环。⑧腕部接口片：左腕金属环箍 + 扁平矩形接口片，片侧一枚小指示灯、正面一条窄数据窗。⑨耳侧接缝扣：耳侧一枚极小金属接缝扣，颧侧一条极细接缝线。所有部件按大体块 + 平涂色画，不做螺丝、铆钉、划痕等细碎装饰。

5. 配色

【配色】主色黑（内层、裙甲、靴筒，约 55%）；辅色深紫（领下承力褶、裙甲外片、鞋面，约 25%，低饱和、偏冷紫，不是亮紫）；点缀色枪灰（领框、腰封、踝环，约 12%）与香槟金（四角锁扣、腰封扣、接口片，约 5%）；冷白到浅青指示灯约 3%，只出现在灯条与接口片。没有暖橙、没有粉色大面积、没有金属镜面。

6. 硬约束

【硬约束】画面里只有这一个角色，单主体、单一姿势；身体结构完整不变形，手指不多不少、四肢不缺不叠；肩线上没有任何装甲片、没有护肩、没有金属块；不出现表外衣物与配件；不做镜像/双人/三视图拼贴；不出现文字、logo、水印、UI 界面元素；不是丝缎礼服、不是晚装。

8. 风格层（全角色共用，原文照抄 `031_角色卡_t2i_20261110.md` 的「风格层 v2」）
