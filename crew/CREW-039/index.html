2. 人物基准（独立设定）

【人物基准】东亚女性角色，视觉年龄 26–30 岁，身高感 170cm，身形有曲线：肩线平、颈长、胸腰臀的转折明显、腿长而匀称，是成熟女性的丰盈感，不是极瘦、不是少女身形。脸是**偏长的心形脸**：额头饱满、颧骨略高但线条柔和、下颌一路收窄、下巴小而略尖；不是圆脸、不是方脸。肤色象牙暖白、有妆底与轻修容。眼是**细长的桃花眼**：眼裂细长、眼尾明显上挑、双眼皮宽、睫毛浓密、眼线拉出一点尾；眼神是冷的、审视的、不太笑。鼻梁高而直、鼻头小而精致。唇中等偏厚、唇峰清晰、玫红满涂。眉毛是有形的挑眉、眉尾上挑。气质冷艳、疏离、夜场女主：站姿直、下巴略抬、手势少而稳。

3. 发型与面容

【发型与面容】纯黑头发全部向上收成**高位松散丸子头**（位于头顶偏后，丸体松而不紧、有几缕抽出的发丝），两侧鬓角各留两三缕细碎发垂到下颌，发顶自然蓬起；不是低发髻、不是长直发、不是大波浪、不是短发、不是双马尾。偏长心形脸、颧略高但柔和、下颌收窄、下巴小尖；细长桃花眼、眼尾明显上挑、双眼皮宽、浓睫、眼线拉尾；挑眉、眉尾上挑；鼻梁高直、鼻头小而精致；唇中等偏厚、唇峰清晰、玫红满涂；象牙暖白肤色、有妆底；妆面是**浓妆但干净**：眼线、睫毛、眉形、玫红唇清楚，没有大面积亮片、没有夸张腮红、没有假睫毛夸张外翻。

4. 服饰（九项）

【服饰·舰载生活区装备·九项】①黑色蕾丝长袖贴身软甲：V 领深到胸线，领缘与袖口一圈蕾丝纹硬质包边，哑光。②分段贴身结构：腰腹与髋部横向褶线按段切开，每段一道窄缝接口。③背部交叉接口带：两条窄带在背中交叉，交点一枚小方扣。④半透黑纱覆层：大腿到脚踝的半透黑纱，接缝一道窄接口线，是覆层不是义体。⑤黑色漆皮尖头硬壳细高跟：尖头、细金属跟、鞋底正红。⑥白色短毛绒披肩甲：搭在双肩、前襟自然分开，毛面按大色块概括。⑦黑色长风衣甲：长及小腿、敞开不系、翻领、无装饰。⑧大圈耳环传感器：细金属圈，直径垂到下颌线，左右各一。⑨锁骨细链 + 左腕宽银接口环：细链一枚小方坠；腕环面宽、哑光银。所有部件按大体块 + 平涂色画，不做亮片、不做蕾丝针脚、不做螺丝与划痕。

5. 配色

【配色】主色纯黑（软甲、风衣、鞋、纱，约 62%）；大块白（毛绒披肩，约 17%）；冷银（耳环、项链、腕环，约 9%）；正红（鞋底、唇，约 8%）；象牙暖白（肤与高光面，约 4%）。整体深色高对比、哑光；红色是唯一的饱和色块；不出紫色、不要荧光、不要金属镜面。

6. 硬约束

【画面铁律】画面里只有这一个角色，单主体、单一姿势；身体结构完整不变形，手指不多不少、四肢不缺不叠；双手空着、不拿酒杯、不拿手机、不拿包；双脚都踩在地面上，高跟鞋穿在脚上、不悬空、不脱脚、不出现第二双鞋；V 领深到胸线但不下滑、不露点；黑纱是覆层，腿部能看到半透的黑，不做关节线、不做红色义体；风衣只在 C 图穿上，A/B 图不穿风衣；不做镜像/双人/三视图拼贴；不出现文字、logo、水印、UI 界面元素。

8. 风格层（全角色共用，原文照抄 `031_角色卡_t2i_20261110.md` 的「风格层 v2」）

【风格层·最高权重】这件作品本身就是一件 3D 角色资产，不是拍摄出来的画面。呈现方式：游戏角色选择界面里的角色展示位（character select screen render），角色站在展示台上、正面朝向镜头、被打光照亮，画面是引擎直出。着色：matcap 着色质感——材质像 matcap 预览球，高光是干净的一块圆形反光，没有环境反射、没有物理正确的镜面拖影。形体：风格化 3D 雕塑（stylized 3D sculpt），面数克制、造型概括，所有面用大块平面交代，转折处是柔软倒角，不做微观起伏。贴图：手绘贴图（hand-painted texture），颜色以平涂色块为主，色块边界清楚，表面看不出照片纹理与细微噪点。光：赛璐璐式分块光（cel-band lighting），亮部 / 灰部 / 暗部三段切开，每段内部是平整的色，阴影边缘干净不糊。质感基调：low poly feel、simplified planes、reduced surface detail、soft matte shading——低细节、哑光、概括，宁可少画也不加细节。展示模型：像 character turnaround model 的一格，均匀展示光、无戏剧性打光。
