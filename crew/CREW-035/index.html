2. 人物基准（独立设定，与 032 / 033 / 034 明确分开）

【人物基准】东亚女性角色，视觉年龄 19–20 岁，身高感 172cm，**极瘦**：肩薄而窄，锁骨与肩胛骨轮廓清楚，手臂与小腿细长、膝与踝的骨点可见，腰极细、胯窄，整体是模特走秀那种「衣架身材」，但不是病态消瘦、脸上仍有精神。脸是短小的 V 脸：脸长偏短、下颌线向内收成窄尖下巴，颧骨位置略高且平，脸颊微凹；额头不宽，颧到下颌之间没有肉感。肤色冷白偏灰青，眼下有一层很淡的倦影。眼型细长、眼尾上挑，内双、眼睑略垂，看人时是自下而上的斜视或平视，眼神倦、不带讨好。鼻梁细直、鼻头小而窄。唇极薄、唇线平直、常态闭合，唇色是低饱和的灰粉。眉毛细、眉尾平直略下压。气质是厌世倦怠的冷：松、懒、不解释，像刚下秀场还没卸妆的模特；不是 032 那种绷着的克制，也不是 033 的温和，更不是 034 的甜。站姿重心压在一条腿上，另一条腿松着，肩略含。

3. 发型与面容

【发型与面容】纯黑长发，中分（偏 1cm），发丝细软、贴头皮、发量中等偏薄，直发垂到胸下，发尾薄而不齐，两侧各留两三缕细碎发丝垂到颧骨与下颌之间；按大束分块概括，每束一条亮带一条暗带，不画一根根碎丝、不做蓬松大波浪。脸短小呈 V 形，下颌收成窄尖下巴，颧骨略高且平，脸颊微凹；眼细长上挑、内双、眼睑略垂；眉毛细、平直、眉尾略下压；鼻梁细直、鼻头小而窄；唇极薄、唇线平直、常闭，唇色灰粉；肤色冷白偏灰青，眼下淡倦影；妆面克制，只有薄底与灰粉唇，没有腮红、没有浓眼线、没有高光。

4. 服饰（九项）

【服饰·舰载生活区装备·九项】①冷灰罗纹软甲背心：整片细竖罗纹复合软甲，哑光，侧缝一道开衩，胸前三道浅压线代替抽褶，圆领不深。②豹纹层压硬壳短外披：驼棕底 + 深褐斑块的大色块豹纹，短到肋下，立领，前襟隐藏式拉链，肩线平直无垫肩。③环毛领密封圈：颈根一圈奶白短毛环，毛向统一、大束分块，下缘一圈窄金属接口环，可拆。④奶白缎面吊带内层：哑光缎面单层，领缘一圈细齿边硅胶密封条，下摆收进裙甲。⑤条纹短甲裙：五片薄硬板叠压，灰黑细横条纹复合面，膝上约 14cm，片间 2mm 深灰缝。⑥铆钉接口腰带：宽黑复合带，正面一排扁圆接口钉，压在裙甲上缘。⑦白色堆叠护胫：双层软壳套筒，自然堆褶三到四道，上缘到小腿中段。⑧软壳平底舞鞋：软壳复合面、薄底、脚背一横一竖两条细绑带，舰内态备选鞋型，首版三张统一穿 ⑨。⑨铆钉硬壳及膝靴：硬壳靴筒到膝下，三圈窄搭扣，小星形钉，方头低粗跟，首版三张都穿这双。所有部件按大体块 + 平涂色画，豹纹斑块不超过掌心大小，不做螺丝、铆钉、划痕等细碎装饰。

5. 配色

【配色】主色冷灰（背心、甲裙底，约 40%）；辅色豹纹驼棕（外披，约 24%）与奶白（毛领、护胫、内层，约 18%）；重色纯黑（腰带、靴筒，约 14%）；点缀冷银（接口钉、搭扣、密封条，约 4%）。整体低饱和、冷调压暗，豹纹是唯一的暖色块；没有金属镜面高光、没有荧光色、没有大面积正红或紫色。

6. 硬约束

【硬约束】画面里只有这一个角色，单主体、单一姿势；身体结构完整不变形，手指不多不少、四肢不缺不叠；双手空着、不拿道具；双脚都踩在地面上，靴子穿在脚上、不悬空、不脱脚、不出现第二双鞋；豹纹只在外披上，不出现豹纹皮肤或豹纹丝袜；不出现表外衣物与配件；不做镜像/双人/三视图拼贴；不出现文字、logo、水印、UI 界面元素。

8. 风格层（全角色共用，原文照抄 `031_角色卡_t2i_20261110.md` 的「风格层 v2」）

【风格层·最高权重】这件作品本身就是一件 3D 角色资产，不是拍摄出来的画面。呈现方式：游戏角色选择界面里的角色展示位（character select screen render），角色站在展示台上、正面朝向镜头、被打光照亮，画面是引擎直出。着色：matcap 着色质感——材质像 matcap 预览球，高光是干净的一块圆形反光，没有环境反射、没有物理正确的镜面拖影。形体：风格化 3D 雕塑（stylized 3D sculpt），面数克制、造型概括，所有面用大块平面交代，转折处是柔软倒角，不做微观起伏。贴图：手绘贴图（hand-painted texture），颜色以平涂色块为主，色块边界清楚，表面看不出照片纹理与细微噪点。光：赛璐璐式分块光（cel-band lighting），亮部 / 灰部 / 暗部三段切开，每段内部是平整的色，阴影边缘干净不糊。质感基调：low poly feel、simplified planes、reduced surface detail、soft matte shading——低细节、哑光、概括，宁可少画也不加细节。展示模型：像 character turnaround model 的一格，均匀展示光、无戏剧性打光。
