# 玄枢号 · 工作台

**线上地址：https://blackinkvc.github.io/xuanshu-hao/**

玄枢号是一套原创科幻舰员设定库：以深空科考舰「玄枢号」为舞台，逐位建立舰员的立绘、档案、机械改造与姿势变体，并保留生成记录（prompt／seed／参数）以便溯源重绘。本仓库只放**工作台网页**与**压缩后的展示图**，是项目的公开查看端，不是素材母库；母库在本地 `D:\玄枢号项目`。

## 一、工作台视图

| 视图 | 路径 | 内容 |
| --- | --- | --- |
| 总览 | `#/` | 30 位舰员卡片、总完成度、重绘队列摘要 |
| 舰员名录 | `#/crew` | HUD 栅格名录：编号角标、待补徽标、完成度细线 |
| 舰员详情 | `#/crew/CREW-0XX` | 主图、透明底开关、八轴雷达、完整档案、系列图墙、克隆切换 |
| 装备库 | `#/gear` | 50 件装备，可按归属舰员筛选；设备↔装备双向跳转 |

桌面 1440 与手机 390 双端适配，无横向滚动。全站统一「舰桥终端」视觉语言：径向深蓝底、发丝线、等宽字距标签、16px 角括号、184/1fr/300 栅格。

## 五、本地母库与回收站

本地主库：`D:\玄枢号项目`

```
01_设定档案/     人物档案、八轴、舱室与装备设定（唯一数据源）
02_人物立绘/     按编号分目录的立绘与分镜母版
03_卷外补充档/   卷外补入的 007/011/027/028/029/030
05_弃用图与过程稿/  废稿、失败占位、过程稿
06_构建与校验脚本/  离线派生 data.js / gear.json / rooms.json 的脚本
08_文档与对账/   编号表、去重清单、改名对照表、执行口径
_回收站_20261109/  判定删除的文件，全部按原相对路径存放
```

回收站机制：

- 任何判定删除的文件**不真删**，移入 `_回收站_20261109\`，保留原相对路径，可原样还原。
- `回收清单.csv` 逐条记录原路径、大小、判定理由、来源卷、回收路径、判定依据、执行时间。
- 去重口径：SHA-256 完全相同才判重，保留分辨率最高、命名最规范的一份；同名不同内容一律保留，按「文件名_尺寸_哈希前8位_vN」改名并记入 `改名对照表.csv`。
- 当前回收站：1897 件 / 364.5 MB；主库 3847 件 / 1.40 GB。
