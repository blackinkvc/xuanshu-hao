# 玄枢号 · 工作台
在线工作台：https://blackinkvc.github.io/xuanshu-hao/

玄枢号是一套原创科幻舰员设定库：以一艘深空科考舰「玄枢号」为舞台，逐位建立舰员的立绘、档案、机械改造与姿势变体，并保留完整生成记录（prompt／seed／参数）以便溯源和重绘。

本仓库只放**工作台网页**与**压缩后的展示图**，是项目的公开查看端，不是素材母库。

## 工作台能看什么

| 视图 | 路径 | 内容 |
| --- | --- | --- |
| 总览 | `#/` | 8 位舰员一页看完：缩略主图 + 姓名代号 + 完成度 + 待补角标 |
| 舰员详情 | `#/crew/CREW-00X` | 主图、完整档案、系列分组图墙；尚未生成/未入档的姿势位用虚线占位块标出，写明缺哪几个、为什么缺 |
| 完成度看板 | `#/board` | 总人数、已入档、待补数量、完成度；每人进度条 + 系列热力格 + 重绘队列 |
| 垃圾站 | `#/trash` | 弃用图区分组折叠，默认收起；展开可见废稿与弃用原因 |

桌面与手机都可看，手机端为两列卡片布局，无横向滚动。

## 目录与素材口径

本地母库（`D:\玄枢号项目`）的原始目录与上线口径：

| 原始目录 | 内容 | 是否上线 |
| --- | --- | --- |
| `01_舰员档案库` | 舰员档案、立绘、manifest、生成记录 | ✅ 上线（图片压缩后） |
| `03_弃用图区_不进档案` | 废稿、失败占位、核验切片 | ✅ 上线（垃圾站，默认折叠） |
| `02_人物示例图库` | 原始示例参考图 | ❌ 明确不上线 |
| `04_待存档工作稿` | 未确认存档的成稿 | ❌ 仅本地 |
| `05_未归档散稿_仅供溯源` | 历史散稿缩略图 | ❌ 仅本地 |

仓库内结构：

```
index.html          工作台单页（总览 / 详情 / 看板 / 垃圾站）
data.js             由 manifest.json + queue.jsonl + 弃用清单离线派生的数据
assets/a/           详情图 900px webp
assets/t/           卡片缩略图 300px webp
assets/x/           垃圾站 560px webp
payload/*.b64       资源分片（GitHub 直连受限，用 API 分片提交，Actions 构建时解包为 assets/）
.github/workflows/  Pages 构建与部署
```

口径说明：

- 立绘以 `manifest.json` 为唯一数据源，一张图一条记录（标题／标签／画幅／seed／参数）。
- 失败生成按约定保留完整 prompt、图位留空，不计入立绘张数；工作台用虚线占位块呈现这些缺位。
- 垃圾站里的图**不写 manifest、不进展示页**，只作过程留档；`08_基准等价副本` 属于等价副本而非判错，单独分组存放。
- 线上图片一律 webp 压缩，原始高分辨率素材只留本地。

## 构建方式

- 页面为无构建依赖的静态单页，直接打开 `index.html` 即可（需与 `data.js`、`assets/` 同目录）。
- 资源不走本机 `git push`（直连 github.com 吞吐极低），改为 base64 分片走 GitHub API 提交，由 Actions 在部署时解包。
- 每次向 `main` 推送后自动重新压缩包并发布 Pages，线上地址固定不变。
